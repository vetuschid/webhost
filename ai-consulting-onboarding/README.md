# 🤖 AI Consultant Onboarding Skill for Claude Code

A Claude Code skill that generates a **complete, professional client onboarding package** in minutes — built specifically for AI consultants, AI auditors, and solopreneurs working in the AI space.

One prompt. Four ready-to-use documents. Zero blank-page panic.

---

## ✨ What It Does

When you tell Claude Code you have a new client to onboard, this skill automatically generates:

| Document | What's included |
|---|---|
| 📋 **Intake Questionnaire** | 15–18 tailored questions based on service type |
| 📧 **Welcome Email** | Warm, professional, ready to send |
| 📄 **Service Agreement** | Plain-language contract with payment terms |
| 📁 **Project Brief** | Scope, milestones, roles, success metrics |

Everything is personalised with the client's name, your name, service type, timeline, and budget — no `[PLACEHOLDER]` brackets left behind.

---

## 🎯 3 Key Benefits

**1. From blank page to professional package in minutes**
No more copy-pasting old contracts or rewriting the same welcome email for every client. One conversation with Claude Code gives you four polished documents, ready to send.

**2. AI-native language built in**
The skill speaks the language of AI consulting — readiness audits, automation workflows, LLMs, prompt engineering, governance — so your documents sound credible and specialist from the start.

**3. Six service types covered**
Whether you're running an AI audit, building automations, delivering training, or starting a retainer, the skill adapts the scope, questions, and expectations automatically.

## 🚀 Installation

```bash
# Clone the repository
git clone https://github.com/diggiehippie-ann/ai-consulting-onboarding.git

# Copy to your Claude Code skills folder
cp -r ai-consulting-onboarding ~/.claude/skills/ai-consultant-onboarding
```

That's it. Claude Code will automatically detect the skill.

---

## 💬 How to Use

Just start a conversation in Claude Code:

```
I have a new client to onboard.
```

Claude will ask for:
- Client name and company
- Service type
- Project scope, timeline, and budget
- Contact details
- Any relevant context (industry, tools, pain points)

Then it generates all four documents in one go.
