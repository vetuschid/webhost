# Asset Registry

## Logos

Place official LensLock logos in:
`/reference_assets/logos`

Rules:
- Use these files as source references whenever logo repair or logo placement is requested.
- Never hallucinate or redraw the logo from memory.

## People

Place approved people / reference faces in:
`/reference_assets/people`

Rules:
- Use only approved reference files.
- If a requested person is unclear, ask before generating.

## Brand examples

Place approved examples in:
`/reference_assets/brand_examples`

Rules:
- Use these for layout / style reference only.
- Do not copy unrelated text or claims from examples.
