# Review Criteria

For every static post or carousel slide, check:

1. **Spelling**
   - Flag typos.
   - Do not rewrite copy unless instructed.

2. **Brand accuracy**
   - Does the image feel consistent with LensLock's professional law enforcement technology brand?

3. **Logo check**
   - Is the LensLock logo present where expected?
   - Is it exact, clean, undistorted, and correctly placed?

4. **Text readability**
   - Is the smallest text readable?
   - Is body text large enough for older viewers or mobile users?
   - Is contrast sufficient?

5. **Text size**
   - If feedback requests text enlargement, preserve hierarchy while increasing size.
   - If all fonts need to be larger, increase carefully without breaking layout.

6. **Layout**
   - Preserve design style.
   - Avoid unnecessary repositioning.
   - Keep balance and spacing clean.

7. **Requested edits**
   - Confirm every human-requested edit is represented in the revision prompt.

8. **Risk**
   - If the edit may alter brand, logo, wording, legal meaning, or client approval artifact, flag for human review.
