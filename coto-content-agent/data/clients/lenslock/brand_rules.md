# LensLock Brand Rules

Client: LensLock
Client type: law enforcement technology

## Core brand requirements
- Maintain professional, clean, trustworthy visual presentation.
- Preserve LensLock logo exactly when present.
- Do not recolor, redraw, distort, stretch, blur, stylize, or reinterpret the LensLock logo.
- Avoid unnecessary visual effects, glows, or dramatic edits.
- Prioritize clarity, readability, authority, and law enforcement professionalism.
- Keep typography clean and scannable.
- Maintain original design intent unless explicit feedback requires a change.

## Logo rules
- LensLock logo must remain exact.
- No blue dot drift.
- No extra marks.
- No alternate logo generation.
- If unsure, use the provided reference logo from `/reference_assets/logos`.

## Image edit rules
- Preserve exact aspect ratio and dimensions.
- Preserve all text unless explicitly told to change wording.
- Preserve background and layout unless explicitly told to adjust.
- Make only requested edits.
- If feedback is ambiguous, ask clarifying questions before generating.
